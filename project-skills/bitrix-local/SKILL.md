- **Webhook:** `SANDBOX_BITRIX_WEBHOOK_URL`

## ⚠️ Критические правила (Update 28.04.2026)
1. **Visibility Logic:** Агент Птенчикова ОБЯЗАНА писать на Общий диск. Запись в личный диск допускается только для логов, не предназначенных для глаз клиента.
