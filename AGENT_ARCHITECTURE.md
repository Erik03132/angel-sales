# Angela: Применение мультиагентного подхода

> На основе: https://habr.com/ru/companies/alpinadigital/articles/1054436/

## Текущее состояние

Angela — один автономный агент, который:
- Классифицирует запросы
- Генерирует ответы
- Работает с FAQ-эталонами
- Использует prompt caching

## Проблема

> "Чем шире задача LLM, тем хуже результат"

Angela пытается делать всё сразу:
- Понимать контекст диалога
- Искать в базе знаний
- Генерировать ответ
- Проверять качество

## Решение: 3 агента

### Agent 1: Router (Workflow - 70%)
```
Вход: сообщение пользователя
Логика: 
  1. Определить роль (CREATOR/BOSS/EMPLOYEE)
  2. Определить тему
  3. Направить к правильному агенту
Выход: { role, topic, agent_id }
```

### Agent 2: Knowledge Base (Workflow - 70%)
```
Вход: { role, topic }
Логика:
  1. Найти FAQ-эталоны
  2. Найти примеры диалогов
  3. Собрать контекст
Выход: { faq, examples, context }
```

### Agent 3: Generator (Autonomous - 30%)
```
Вход: { role, topic, faq, examples, context }
Логика:
  1. Сгенерировать ответ
  2. Проверить качество
  3. Отформатировать
Выход: ответ пользователю
```

## Пропорция 70/30

| Компонент | Тип | % | Пример |
|-----------|-----|---|--------|
| Router | Workflow | 20% | Детерминированные правила |
| Knowledge Base | Workflow | 50% | Поиск в FAQ |
| Generator | Autonomous | 30% | LLM для генерации |

## 4-этапное внедрение

### Этап 1: Фон (2 недели)
- Angela работает как обычно
- Параллельно тестируем 3 агента
- Сравниваем качество

### Этап 2: Полноценное (2-3 недели)
- 3 агента работают в тени
- Собираем метрики
- Сравниваем с monolith

### Этап 3: Перед ревью (3-4 недели)
- 3 агента becomes primary
- Monolith как fallback
- Собираем фидбэк

### Этап 4: Полная интеграция
- Только 3 агента
- Monolith удалён

## Метрики

| Метрика | Цель | Как замерять |
|---------|------|--------------|
| Время ответа | <2s | Time tracking |
| Точность | >90% | A/B тест |
| Стоимость | <$0.01/диалог | API cost |
| Доверие | >80% | Опросы |

## Что НЕ автоматизировать

| Задача | Решение | Причина |
|--------|---------|---------|
| Принятие решений | Только советы | Доверие хрупкое |
| Юридические консультации | Человек | Ответственность |
| Финальные ответы | Человек проверяет | Репутация |
