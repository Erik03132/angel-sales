# 🔄 ОБЯЗАННОСТЬ: Синхронизация цен — ЖЕЛЕЗНОЕ ПРАВИЛО

## Источники цен (приоритет)
1. **Битрикс24 CRM** — товары/каталог (crm.product.*)
2. **Заботкина/менеджер** — прямое указание в чате
3. **Официальные каналы Инкубатора**: сайт Инкубатора, VK группа, ОК, МАКС

## Каналы обновления (ВСЕ обновляются ОДНОВРЕМЕННО)
При любом изменении цены — НЕМЕДЛЕННО обновить:
1. **vezemcip.ru** — Products.astro → productsData → pricing
2. **VK каталог** — market.edit через API (VK_VEZEMCYP_*)
3. **ОК каталог** — когда подключим
4. **МАКС** — когда подключим
5. **Telegram** — когда подключим
6. **Яндекс Дзен** — когда подключим

## Триггеры
- Заботкина увидела изменение цены в чате Битрикса → обновить ВСЕ каналы
- Менеджер написал новую цену → обновить ВСЕ каналы
- Раз в неделю — сверка цен по ВСЕМ каналам (audit)

## Формат обновления
```python
# VK Market
vk.market.edit(owner_id='-GID', item_id=ID, price=NEW_PRICE)

# Сайт vezemcip.ru
# Файл: vezem/src/components/Products.astro
# Массив productsData → найти по id → обновить pricing
```
