## 1. Ежедневный отчёт Заботкиной по Битрикс CRM

**Скрипт:** `agent/manual_report.py` (ручной) / `agent/daily_report.py` (авто)  
**Время формирования:** ежедневно в 20:00 MSK  
**Получатели в Telegram:** Игорь (176203333)  
**⚠️ Андрею — НИКАКИХ отчётов в TG!** (решение от 12.05.2026)  
**Источник данных:** Bitrix24 CRM (скан `bitrix_scanner.py`) + 1С (поля UF_CRM)

### Структура отчёта:

```
══════════════════════════════════════════
📋 ЕЖЕДНЕВНЫЙ ОТЧЁТ — ДД.ММ.ГГГГ
⏰ Сформирован: ЧЧ:ММ MSK
══════════════════════════════════════════

📊 CRM BITRIX24
   Источник: файл скана (свежесть)
   Период: начало → конец

   🆕 Сделки: N (на X₽)
   📞 Звонки: N
   💬 Чаты: N
   📱 SMS: N
   📋 Веб-формы: N

   👩‍💼 По менеджерам:
      • Менеджер1: N сделок, N звонков (X₽)
      • Менеджер2: ...

   📈 Конверсия (сделки / лиды): X%

   📊 СТАТУС СДЕЛОК (где что):
      🆕 Новые: N шт. (X₽)
         → X₽ — Покупатель (Менеджер)
      🔄 Повторное обращение: N шт.
      ⏳ Ожидает предоплаты: N шт.

   ⏰ ЗАБЫТЫЕ СДЕЛКИ (если есть)

   📥 ЛИДЫ: N

   🐔 ТОП ПРОДАЖ (что покупают):
      • Порода: N шт. (X₽, N сделок)

   💰 ОПЛАТЫ (1С):
      ✅ Оплачено: N сделок (X₽)
      ⏳ Не оплачено: N сделок (X₽)

──────────────────────────────────────────

📞 ЗВОНКИ
   Состоявшихся: N
   ⚠️ Пропущенных: N (по менеджерам)

   👩‍💼 Звонки по менеджерам:
      • Менеджер: N звонков + N пропущ.

──────────────────────────────────────────

💡 ВЫВОДЫ АНЖЕЛОЧКИ:
   AI-анализ (DeepSeek/Gemini)

──────────────────────────────────────────

📢 VK / РОАДМАП (информационно)

──────────────────────────────────────────
🐥 Отчёт собран Antigravity (IncuBird v2)
```

### Ключевые секции:
1. **CRM** — сделки, лиды, менеджеры, суммы
2. **Воронка** — статусы сделок с ТОП-3 крупнейших
3. **Забытые сделки** — без движения >3 дней
4. **Лиды** — новые заявки с источниками
5. **Породы** — что покупают (из товарных строк 1С)
6. **Оплаты 1С** — оплачено / не оплачено
7. **Звонки** — статистика + пропущенные
8. **AI-выводы** — анализ через LLM каскад

## 2. Отчёт по качеству телефонных разговоров

**Скрипт:** `agent/call_quality_report.py` *(в разработке)*  
**Время формирования:** ежедневно после основного отчёта  
**Источник данных:** Bitrix24 поле `bitrixgpt_summary` (AI-резюме каждого звонка)

### Структура отчёта:

> ⚠️ ПРЕДЛОЖЕНИЕ — ОЖИДАЕТ УТВЕРЖДЕНИЯ

```
══════════════════════════════════════════
📞 ОТЧЁТ ПО КАЧЕСТВУ ЗВОНКОВ — ДД.ММ.ГГГГ
⏰ Проанализировано: N звонков из M
══════════════════════════════════════════

👩‍💼 ПРОФИЛЬ МЕНЕДЖЕРА: Марина Е
   📊 Статистика:
      Звонков с содержанием: N
      Входящих: N | Исходящих: N
      Средняя длительность: Xм
   
   ✅ Сильные стороны:
      • [конкретные примеры хорошей работы]
   
   ⚠️ Зоны роста:
      • [конкретные проблемы]
   
   🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ:
      • [грубость, неответы на вопросы и т.д.]

   📝 Примеры разговоров:
      🟢 Хороший: [саммари]
      🔴 Проблемный: [саммари]

──────────────────────────────────────────

👩‍💼 ПРОФИЛЬ МЕНЕДЖЕРА: Эльзара
   [аналогичная структура]

──────────────────────────────────────────

📊 СВОДНАЯ ТАБЛИЦА КАЧЕСТВА

   Менеджер     | Звонков | Оценка | Приветствие | Прощание | Знание товара
   Марина Е     |   36    |  4.2   |    ✅/❌     |   ✅/❌   |    ✅/❌
   Эльзара      |   22    |  3.8   |    ✅/❌     |   ✅/❌   |    ✅/❌

──────────────────────────────────────────

🔍 ТИПИЧНЫЕ ПРОБЛЕМЫ ДНЯ:
   1. [описание повторяющейся проблемы]
   2. [...]

📈 РЕКОМЕНДАЦИИ:
   1. [конкретное действие]
   2. [...]

──────────────────────────────────────────

🔥 ТОП-5 ПРОБЛЕМНЫХ ЗВОНКОВ:
   🔴 1. [Менеджер] — [суть проблемы]
   🔴 2. ...

🏆 ТОП-3 ЛУЧШИХ ЗВОНКА:
   🟢 1. [Менеджер] — [чем хорош]
   🟢 2. ...

──────────────────────────────────────────

💡 AI-ВЕРДИКТ АНЖЕЛОЧКИ:
   [общая оценка работы отдела + рекомендации]

══════════════════════════════════════════
📞 Анализ: Анжела Заботкина | IncuBird v2
```

### Критерии анализа (из bitrixgpt_summary):

| # | Критерий | Что ищем в саммари | Вес |
|---|----------|-------------------|-----|
| 1 | **Приветствие** | Наличие стандартного приветствия | 10% |
| 2 | **Прощание** | Корректное завершение разговора | 10% |
| 3 | **Знание товара** | Менеджер ответил на вопросы о породах/ценах/доставке | 20% |
| 4 | **Результативность** | Заказ оформлен / дата согласована / контакт взят | 25% |
| 5 | **Работа с возражениями** | Предложена альтернатива при отказе | 15% |
| 6 | **Сбор контактов** | ФИО, email, адрес зафиксированы | 10% |
| 7 | **Инициативность** | Предложение допродажи / кросс-продажи | 10% |

### Автоматические метки из содержания звонков:

- 🔴 `«Диалог не содержит достаточной информации»` → пустой звонок
- 🔴 `«Заказ не оформлен»` → упущенная возможность  
- 🔴 `«Контактные данные не предоставлены»` → не взяли контакт
- 🟡 `«Ожидается повторное обращение»` → клиент уходит думать
- 🟢 `«Заказ подтвержден»` → успешная продажа
- 🟢 `«Доставка запланирована»` → сделка закрыта

## Технические заметки

- Отчёт Заботкиной (CRM) использует скан `bitrix_scanner.py`
- Отчёт Птенчиковой использует `report-day` и хроники (НЕ Битрикс)
- Отчёт по звонкам запускается после `call_transcriber.py` + `call_learner.py`
- Поле `bitrixgpt_summary` доступно из Bitrix24 API для звонков
- Для глубокого анализа нужны **транскрипты**, а не саммари
