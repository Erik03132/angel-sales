# 🔑 SSoT: Источники данных для отчётов IncuBird

> **Дата:** 11.06.2026
> **Причина:** Расхождение отчётов 1С vs Bitrix

## 🚨 Проблема

Суммы в отчётах Анжелочки (из Bitrix) **не совпадают** с 1С, потому что:

1. **OPPORTUNITY** (Bitrix) = сумма сделки, которую ввёл менеджер. Может быть
   приблизительной, без НДС, без учёта скидок/возвратов.
2. **UF_CRM_1641882450** (1С → Bitrix) = фактическая сумма оплаты из 1С.
   Но это поле **не всегда заполнено** — и тогда fallback на OPPORTUNITY.

## ✅ Правило SSoT (Single Source of Truth)

| Тип данных | Источник | Поле/API | Примечание |
|------------|----------|----------|------------|
| **Выручка (деньги)** | 1С → UF-поля | `UF_CRM_1641882450` | Только если заполнено |
| **Факт оплаты** | 1С → UF-поля | `UF_CRM_1641882420` | Флаг "Уже оплачено" |
| **Сумма сделки (план)** | Bitrix | `OPPORTUNITY` | Планируемая, не факт! |
| **Количество сделок** | Bitrix | `crm.deal.list` | ОК для подсчёта |
| **Конверсия воронки** | Bitrix | `STAGE_ID` | ОК |
| **Активность менеджера** | Bitrix | Звонки, чаты | ОК |
| **Номенклатура** | Bitrix (из 1С) | Product rows | ОК, синхронизируются |

## 📋 Маппинг UF-полей 1С в Bitrix

| UF-поле | Назначение | Тип |
|---------|-----------|-----|
| `UF_CRM_3713038619599` | Номер документа 1С | string |
| `UF_CRM_3713038619596` | Удалён в 1С (флаг) | boolean |
| `UF_CRM_3713038619602` | Организация | string |
| `UF_CRM_1641882420` | Уже оплачено (флаг) | boolean |
| `UF_CRM_1641882450` | Сумма оплаты (факт) | number |
| `UF_CRM_1773835772534` | Номер оплаты | string |
| `UF_CRM_1773923024769` | Номер заказа | string |
| `UF_CRM_1557837472437` | Адрес доставки | string |
| `UF_CRM_1557837504964` | Дата доставки | date |

## 🔧 Что изменить в коде

### 1. В отчётах: приоритет UF_CRM_1641882450 над OPPORTUNITY

```python
# БЫЛО (неправильно):
deal_sum = float(d.get("OPPORTUNITY", 0) or 0)

# СТАЛО (правильно):
paid_1c = d.get("UF_CRM_1641882450")
if paid_1c and float(paid_1c) > 0:
    deal_sum = float(paid_1c)          # Факт из 1С
    source = "1С"
else:
    deal_sum = float(d.get("OPPORTUNITY", 0) or 0)  # План из Bitrix
    source = "Bitrix (план!)"
```

### 2. В отчётах: помечать источник суммы

```
💰 ОПЛАТЫ:
   ✅ Оплачено (1С): 12 сделок (847 200₽) ← ФАКТ
   ⏳ Не оплачено: 5 сделок (234 500₽) ← план Bitrix
   ⚠️ Расхождение план/факт: 3 сделки (Bitrix: 156K, 1С: 142K)
```

### 3. Автоматическая сверка раз/неделю

Скрипт сравнивает OPPORTUNITY vs UF_CRM_1641882450 и алертит расхождения > 5%.

## 📊 Ожидаемый результат

- Финансовые цифры в отчёте = данные 1С (факт)
- Менеджерская активность = данные Bitrix (ОК)
- Претензии «не бьётся с 1С» → исчезнут на 80%+
