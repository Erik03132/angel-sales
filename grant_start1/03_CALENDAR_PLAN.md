# Календарный план выполнения НИОКР (по требованиям Фонда Бортника)
## Проект: «Интеллектуальная система предиктивного сбыта и управления логистикой агропредприятия»
**Срок реализации:** 12 месяцев
**Сумма грантового финансирования:** 4 000 000 рублей

---

### Этап 1. Исследование и проектирование архитектуры ИИ-модуля (Месяцы 1-3)
**Цель этапа:** Разработка базовых алгоритмов предиктивной аналитики и проектирование базы знаний (векторной БД).
*   **Месяц 1:** Сбор исторических данных (продажи, диалоги, логистика). Очистка и разметка данных. Формирование онтологии агро-терминов для RAG-архитектуры.
*   **Месяц 2:** Проектирование архитектуры базы данных (Vector DB) и системы управления контекстом для LLM. Обучение классификатора намерений (Intent Classifier) для аграрной отрасли.
*   **Месяц 3:** Разработка первой версии модуля «Shadow Mode». Сборка прототипа системы (backend) для тестирования гипотез. Написание отчета по первому этапу.

### Этап 2. Разработка омниканального интерфейса и интеграция (Месяцы 4-6)
**Цель этапа:** Обеспечение бесшовного взаимодействия системы с популярными каналами продаж (Avito, VK, TG) и CRM.
*   **Месяц 4:** Проектирование и создание API-коннекторов для мессенджеров и маркетплейсов (VK, Telegram, Avito).
*   **Месяц 5:** Интеграция ИИ с Bitrix24 (REST API / Webhooks) для двустороннего обмена данными.
*   **Месяц 6:** Настройка триггеров перевода на оператора (Fallback mechanism). Создание внутренней документации на API и интерфейсы. Сдача промежуточного этапа.

### Этап 3. Разработка логистического AI-движка и предиктивного модуля (Месяцы 7-9)
**Цель этапа:** Реализация алгоритмов динамического ценообразования и построения логистических маршрутов.
*   **Месяц 7:** Разработка алгоритма "Живая Логистика" для распределения доставок скоропортящихся грузов (птицы/яиц) по кластерам.
*   **Месяц 8:** Создание модуля предиктивной аналитики спроса на основе парсинга внешних сигналов (Avito Analytics).
*   **Месяц 9:** Интеграция алгоритмов в единый контур управления рекламными кампаниями. Альфа-тестирование внутри команды разработчиков.

### Этап 4. Пилотные испытания, внедрение и формирование отчета о НИОКР (Месяцы 10-12)
**Цель этапа:** Стресс-тестирование системы на реальном трафике Азовского инкубатора и подготовка итоговой документации.
*   **Месяц 10:** Развертывание системы на серверной инфраструктуре предприятия. Старт бета-тестирования в изолированных каналах продаж (например, только Telegram).
*   **Месяц 11:** Полномасштабные пилотные испытания на входящем трафике Авито и VK. Сбор статистики, отладка LLM-аллокации и устранение галлюцинаций.
*   **Месяц 12:** Анализ полученных результатов (сокращение CAC, высвобождение часов менеджеров, улучшение логистики). Оформление Свидетельства о государственной регистрации программы для ЭВМ (Роспатент). Сдача итогового отчета о НИОКР в Фонд содействия инновациям.
