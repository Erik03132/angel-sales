# CONTEXT.md — ai-eggs (Angela)

> Shared language for Angela project
> Based on: https://github.com/mattpocock/skills

## Domain Terms

**Angela**:
AI-менеджер по продажам птицы. Работает в Telegram, на сайте, в Bitrix24.
_Избегай_: бот, ассистент, помощник

**Роль**:
Классификация пользователя: CREATOR, BOSS, EMPLOYEE, CUSTOMER.
_Избегай_: тип пользователя, категория

**Тир**:
Уровень сложности запроса для маршрутизации LLM: LITE, STD, PRO.
_Избегай_: модель, уровень

**FAQ-эталон**:
Качественный ответ на типовой вопрос, сохранённый в кэш для мгновенной выдачи.
_Избегай_: шаблон, заготовка

**SmartFAQ**:
Автоматический кэш, который кэширует ответы при 3+ повторениях вопроса.
_Избегай_: кэширование, хранилище

**Prompt caching**:
Кэширование системного промпта в Anthropic API для экономии ~90%.
_Избегай_: кэширование промптов, economy mode

**Multi-agent**:
Архитектура из 3 агентов: Router + KnowledgeBase + Generator.
_Избегай_: мультиагентная система, архитектура агентов

**Phone-First Protocol**:
Правило: корм и допы предлагаем ТОЛЬКО после получения телефона клиента.
_Избегай_: протокол телефона, сбор телефона

## Relationships

- **Angela** имеет одну **Роль** для каждого пользователя
- **Роль** определяет доступ к **FAQ-эталонам**
- **Тир** определяет стоимость **LLM** вызова
- **Multi-agent** использует **Router** для определения **Роли**
- **SmartFAQ** автоматически создаёт **FAQ-эталоны**

## Flagged Ambiguities

- "бот" vs "менеджер" — resolved: используем "менеджер" (Angela)
- "модель" vs "тир" — resolved: "тир" для маршрутизации, "модель" для LLM
- "кэш" vs "SmartFAQ" — resolved: SmartFAQ для автоматического кэша
- "промпт" vs "системный промпт" — resolved: "системный промпт" для инструкций LLM
