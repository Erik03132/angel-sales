# 📞 Скрипт автодозвона: Подтверждение заказа

**Тип:** Исходящий звонок для подтверждения заказа  
**Триггер:** Новый лид в CRM за 24 часа до доставки  
**Цель:** Подтверждение готовности клиента к приёму заказа

---

## 🎯 Основная цель звонка

1. **Подтвердить** актуальность заказа
2. **Предупредить** о времени доставки
3. **Зафиксировать** ответ клиента (DTMF-код)
4. **Снизить** процент отказа при получении

---

## 📜 Текст сценария (TTS)

### Базовая версия (19-20 секунд)

```
Андрей, добрый вечер! Это Анжела Заботкина, Азовский Инкубатор.

Вы заказали 100 гусят с доставкой в Джанкой на 15 мая.

<пауза 0.5 сек>

Водитель свяжется с вами завтра утром.

Если заказ в силе — нажмите 1.
Если нужна переноска — нажмите 0.

<пауза 0.5 сек>

Мы перезвоним для уточнения деталей. Спасибо!
```

**Длительность:** ~19 сек  
**Тон:** Профессиональный, дружелюбный, без излишней фамильярности

---

## 🎙️ Параметры синтеза (Gemini TTS)

```yaml
voice: Kore          # нейтральный, профессиональный
pitch: 0.0           # без изменений
rate: 0.95           # чуть медленнее для чёткости
volume: 0.0 dB       # нормальная громкость
style: professional  # деловой тон
```

**Паузы:**
- После приветствия: 300ms
- После информации о заказе: 500ms (осмысление)
- Перед инструкцией DTMF: 400ms
- После инструкции: 600ms (время на реакцию)
- Финальная пауза: 300ms

---

## 🔢 DTMF-коды ответа

| Код | Значение | Действие системы |
|-----|----------|------------------|
| `1` | ✅ Подтверждаю | Обновить статус → «Подтверждён» → Уведомить менеджера |
| `0` | ❌ Не актуально | Обновить статус → «Требует перезвона» → Задача менеджеру |
| Нет ответа | 📞 Не взял трубку | Повтор через 2 часа / задача менеджеру |

---

## 🔄 Сценарии развития

### ✅ Клиент нажал 1

```
→ Статус лида: «Подтверждён»
→ Задача водителю: «Доставка в Джанкой, 15 мая, 100 гусят»
→ Уведомление менеджеру: «Заказ #123 подтверждён клиентом»
→ SMS клиенту: «Ваш заказ подтверждён. Водитель свяжется завтра.»
```

### ❌ Клиент нажал 0

```
→ Статус лида: «Требует перезвона»
→ Задача менеджеру: «Уточнить дату доставки (клиент переносит)»
→ Приоритет: Высокий (срок доставки близко)
```

### 📞 Нет ответа / Гудки

```
→ Попытка 1: 14 мая, 18:00 (текущая)
→ Попытка 2: 14 мая, 20:00 (через 2 часа)
→ Попытка 3: 15 мая, 09:00 (утром)
→ После 3-й попытки → Задача менеджеру
```

| **Отказ** | < 5% |

---

## 🛠️ Технические требования

### Аудиофайл

- **Формат:** WAV, PCM 24kHz, 16-bit, mono
- **Длительность:** 18-22 сек
- **Размер:** ~900-1100 КБ
- **Качество:** Чёткая дикция, без шумов

### Интеграция

- **Телефония:** Mango Office API (`calls/outbound`)
- **TTS:** Gemini 2.5 Flash Preview TTS
- **CRM:** Bitrix24 webhook (статусы, задачи)
- **Уведомления:** Telegram-бот
