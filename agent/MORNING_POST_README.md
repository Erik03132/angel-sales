# ☀️ MORNING POST — Утренний генератор контента

**Файл:** `ai-eggs/agent/morning_post.py`

---

## 📋 Назначение

Автоматическая генерация контента для соцсетей с приоритетом готовых постов из `/ok/`.

---

## 🔄 Алгоритм работы

```
1. Утро (09:30 MSK) → запуск morning_post.py
   ↓
2. Проверка /ok/YYYY-MM-DD_XX/ на сегодня
   ↓
3. Если есть классический пост (не ТЗ):
   → Берём post.txt + photo.png
   → Пропускаем ТЗ для видео/медиа
   ↓
4. Если нет:
   → Генерируем новое (Тихон Полеванов / коммерческий)
   → Генерируем фото (Imagen 4.0 / Unsplash)
   → Сохраняем в /ok/
   ↓
5. Отправка превью в TG Игорю с кнопками
   ↓
6. Игорь нажимает кнопку → Публикация в каналы
```

---

## 📱 TG-кнопки

```
┌─────────────────────────────────────────┐
│  ✅ Отправить       🔄 Ещё              │
│  📡 Только Дзен     📡 Только VK        │
│  🗑 Удалить                             │
└─────────────────────────────────────────┘
```

| Кнопка | Действие |
|--------|----------|
| **✅ Отправить** | Публикация во все каналы (TG → VK → Дзен) |
| **🔄 Ещё** | Генерация альтернативного поста |
| **📡 Только Дзен** | Публикация только в Дзен |
| **📡 Только VK** | Публикация только в VK |
| **🗑 Удалить** | Удалить превью из TG (очистка ленты) |

---

## 🗂 Формат постов в /ok/

**Структура папок:**
```
/ok/
├── 2026-05-16_01/
│   ├── post.txt      ← Текст поста
│   └── photo.png     ← Фото (Imagen 4.0)
├── 2026-05-16_02/
│   ├── post.txt
│   └── photo.png
└── ...
```

**Фильтр ТЗ:**
- ❌ Исключаются посты с маркерами: `📹 ТЗ ДЛЯ ВИДЕО`, `VK Clip`, `Сценарий:`, `КАДР 1`, и т.д.
- ✅ Берутся только классические посты (текст + хэштеги)

## 🎨 Генерация фото

**Каскад (приоритет):**
1. **Imagen 4.0** (Gemini API через US прокси)
2. **Unsplash** (стоковое фото)
3. **Pexels** (стоковое фото)
4. **Pixabay** (стоковое фото)

**Ключевые слова:** Извлекаются из первой строки поста.
