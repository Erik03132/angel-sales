# 📞 Мой вариант скрипта автодозвона

**Философия:** Коротко, ясно, по-деловому — но без канцеляризмов.  
**Принцип:** 3 секунды на идентификацию → 10 секунд на суть → 5 секунд на действие

---

## 🎯 Структура идеального звонка

```
┌─────────────────────────────────────────────────────┐
│  1. Кто звонит (2-3 сек)                            │
│  2. Зачем звоним (5-7 сек)                          │
│  3. Что делать (3-4 сек)                            │
│  4. Пауза на ответ (2-3 сек)                        │
│  5. Завершение (2 сек)                              │
└─────────────────────────────────────────────────────┘
        ИТОГО: 14-19 секунд
```

---

## ✅ МОЙ ВАРИАНТ (17 секунд)

```
Андрей, добрый вечер! Это Анжела, Азовский Инкубатор.

Вы заказали 100 гусят на 15 мая, Джанкой.

Водитель позвонит вам завтра.

Для подтверждения — нажмите 1.
Для переноса — нажмите 0.

Спасибо!
```

**Почему так:**

| Фраза | Зачем | Время |
|-------|-------|-------|
| «Андрей, добрый вечер!» | Персонализация, контакт | 2 сек |
| «Это Анжела, Азовский Инкубатор» | Идентификация (без «Заботкина» — короче) | 3 сек |
| «Вы заказали 100 гусят на 15 мая, Джанкой» | Суть: что, когда, куда | 5 сек |
| «Водитель позвонит вам завтра» | Следующий шаг (спокойствие) | 2 сек |
| «Для подтверждения — нажмите 1...» | Действие (чётко, пауза перед цифрами) | 4 сек |
| «Спасибо!» | Позитивный финал | 1 сек |

---

## 🎙️ Параметры для TTS

```yaml
voice: Puck          # тёплый, но деловой (не Kore — он слишком сухой)
pitch: +0.3          # чуть выше — дружелюбнее
rate: 0.92           # чуть медленнее — чётче цифры
volume: +1.0 dB      # чуть громче — увереннее

# Паузы в тексте:
"Андрей, добрый вечер! <pause:200ms> Это Анжела, Азовский Инкубатор.
<pause:300ms> Вы заказали 100 гусят на 15 мая, Джанкой.
<pause:400ms> Водитель позвонит вам завтра.
<pause:500ms> Для подтверждения — нажмите 1. <pause:300ms> Для переноса — нажмите 0.
<pause:400ms> Спасибо!"
```

**Общая длительность:** ~17 сек  
**Эмоция:** Уверенная, тёплая, без заискивания

## 🔄 Альтернативные версии

### Если клиент «тёплый» (уже общался с менеджером)

```
Андрей, добрый вечер! Анжела, Азовский Инкубатор.

По вашему заказу: 100 гусят, 15 мая, Джанкой — всё готово.

Водитель завтра позвонит. Подтверждаете? Нажмите 1.

Спасибо!
```
**14 секунд** — короче, потому что клиент в контексте

### Если клиент «холодный» (первый заказ)

```
Андрей, добрый вечер! Это Анжела Заботкина, Азовский Инкубатор.

Благодарим за заказ! Вы заказали 100 суточных гусят с доставкой в Джанкой на 15 мая.

Если дата неудобна — нажмите 0, мы перезвоним.

Спасибо за доверие!
```
**24 секунды** — больше заботы, потому что клиент новый

## 🚫 Что я убрал из оригинала

| Было | Стало | Почему |
|------|-------|--------|
| «Вы недавно сделали заказ» | «Вы заказали» | Коротче, без «недавно» (очевидно) |
| «с доставкой в» | (убрал) | Лишние слова, «Джанкой» сам по себе ясен |
| «Если вы подтверждаете заказ на завтра» | «Для подтверждения» | Короче, без условия |
| «Если у вас не получится» | «Для переноса» | Позитивнее, без негатива |
| «Мы свяжемся с вами для уточнения» | (убрал) | Лишняя угроза — и так перезвонят |
| «Всего доброго!» | «Спасибо!» | Коротче, позитивнее |

## 📊 Психология звонка

**Что важно:**

1. **Имя в начале** — сразу внимание (не «Здравствуйте, это...»)
2. **Кто звоним** — за 3 сек (иначе положат трубку)
3. **Цифры чётко** — «100 гусят», «15 мая» (пауза до и после)
4. **Одно действие** — не «1 или 0», а «1... 0» (раздельно)
5. **Позитивный финал** — «Спасибо!» (остается приятное)

**Что НЕ делать:**

- ❌ «Извините за беспокойство» (извиняемся = слабость)
- ❌ «Вас беспокоит...» (сразу негатив)
- ❌ «Мы хотели бы уточнить...» (канцелярит)
- ❌ Длинные паузы между фразами (клиент заскучает)
- ❌ «Нажмите любую кнопку» (непонятно, какую)
